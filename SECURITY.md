# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) for this repository (Security tab → "Report a vulnerability") when available. If it is unavailable, contact the repository maintainer privately through their GitHub profile and include a minimal reproduction, affected version, impact, and any suggested mitigation.

Do not include credentials, live hub URLs, database contents, or customer data in a report. We will acknowledge a valid report, investigate it, coordinate a fix, and request a disclosure window when appropriate.

## Supported versions

Security fixes are made for the latest released minor version of cloud-pulse. The currently supported line is `v0.7.x`; users of older releases should upgrade before requesting a security fix where possible.
