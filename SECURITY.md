# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues. Use GitHub's private vulnerability-reporting flow for this repository when available. If it is unavailable, contact the repository maintainer privately through their GitHub profile and include a minimal reproduction, affected version, impact, and any suggested mitigation.

Do not include credentials, live hub URLs, database contents, or customer data in a report. We will acknowledge a valid report, investigate it, coordinate a fix, and request a disclosure window when appropriate.

## Supported versions

Security fixes are made for the latest released minor version of cloud-pulse. During the v0.5 development cycle, the supported line is `v0.5.x`; users of older releases should upgrade before requesting a security fix where possible.
